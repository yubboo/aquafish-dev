# core

## 模块定位

框架核心能力：配置、路径、数据库连接、迁移、安装状态、安全基础和通用底座。

## 当前工程信息

- 项目相对路径：`app/core`
- 主源码 Java 文件：98 个
- 测试 Java 文件：35 个
- Gradle 项目依赖：无其他 Aquafish 模块依赖

## 模块边界

- 只能承担本模块职责，不把其他领域实现集中进来。
- 数据库在线访问统一使用 R2DBC。
- 数据库结构变化通过模块迁移资源声明。
- 不允许新增 Flyway 运行时或在线 JDBC 热路径。
- 路径、表前缀、迁移文件和版本必须通过配置、注册表或真实目录扫描取得。

## 验证

模块修改后先运行 `:core:compileJava`、`:core:compileTestJava` 和 `:core:test`，阶段收口前运行全工程 `clean test`。
