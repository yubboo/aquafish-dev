# Aquafish 安装器接口索引

> 只记录接口职责；请求体和错误码以源码及后端测试为准。

| 方法 | 路径 | 职责 |
|---|---|---|
| GET | /api/setup/status | 安装状态和是否允许进入安装器 |
| GET | /api/setup/context | 可信部署上下文、环境和托管模式 |
| POST | /api/setup/database/test | 分发包数据库真实连接测试 |
| POST | /api/setup/database/managed/test | 托管数据库真实连接测试 |
| POST | /api/setup/database/inspect | 分发包数据库身份识别 |
| POST | /api/setup/database/managed/inspect | 托管数据库身份识别 |
| POST | /api/setup/redis/test | 分发包 Redis AUTH / SELECT / PING |
| POST | /api/setup/redis/managed/test | 托管 Redis 测试 |
| POST | /api/setup/recovery/existing | 恢复已有完整安装 |
| POST | /api/setup/database/reset | 精确清理 Aquafish 白名单表并回到首次安装 |

## 约束

- 安装状态接口和准备接口受安装锁、开发维护入口和后端过滤器保护。
- reset 不能信任前端旧检测结果，必须重新检查数据库。
- 托管接口不向浏览器返回数据库和 Redis 密码。
