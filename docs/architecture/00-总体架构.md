# Aquafish 总体架构

> 当前架构摘要，不替代源码和根目录 CLAUDE.md。

## 架构形态

Aquafish 当前采用模块化单体。后端由 Spring Boot 多模块组成，管理端使用 Vue 3 + TypeScript。主题、插件、用户、认证、安装、授权等能力通过明确模块边界组织。

## 关键目录

- `app/core`：核心能力。
- `app/setup`：首次安装、恢复和重装。
- `app/auth`：认证与授权。
- `app/user`：用户领域。
- `app/theme`：主题系统。
- `app/plugin`：插件系统。
- `admin/src`：管理端页面、API 和状态。

## 数据与缓存

- PostgreSQL 为长期重点兼容对象之一。
- MySQL、MariaDB、PostgreSQL 均由安装器真实选择和测试。
- Redis 可选；未启用时必须有数据库或内存回退。
- 表前缀和数据库状态识别属于安装器安全边界。

## 重要原则

- 安装器、主题、插件、认证都不能绕过后端权威状态。
- 浏览器不得接触 Docker / 1Panel 注入的数据库密码。
- 主题删除或损坏时必须有核心层兜底。
- 插件和主题扩展必须遵守权限与生命周期边界。
