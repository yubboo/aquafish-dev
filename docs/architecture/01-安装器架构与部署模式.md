# Aquafish 安装器架构与部署模式

> P0-3-2B 最终实现规则。

## 两类部署模式

### 分发包安装

浏览器需要完成数据库和 Redis 选择、填写、真实测试以及数据库身份识别。

服务配置分为两个小步骤：

1. 数据库三选一，Redis 卡片位于下方作为可选增强。
2. 左侧数据库、右侧 Redis，同时填写并真实测试。

### Docker / 1Panel 托管安装

部署平台已经确定数据库和 Redis。安装器通过可信服务端上下文识别 `databaseManaged` / `redisManaged`，跳过整个服务配置步骤。平台密码不得重新进入浏览器。

## 状态来源

- 前端只展示状态。
- 后端负责连接测试、数据库身份识别、迁移状态和安全重装白名单。
- 前端不得根据表单或旧缓存猜测数据库状态。

## 安装器页面

正式流程保持环境检测、服务配置、站点与管理员、安装、完成五个主步骤；托管部署可按可信上下文跳过服务配置。
