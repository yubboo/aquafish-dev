# Aquafish 部署模式差异

> 分发包和托管部署必须保持明确边界。

| 能力 | 分发包 | Docker / 1Panel |
|---|---|---|
| 浏览器选择数据库 | 是 | 否 |
| 浏览器填写数据库密码 | 是 | 否 |
| 浏览器选择 Redis | 是 | 否，由部署配置决定 |
| 服务配置步骤 | 两小步 | 整体跳过 |
| 数据库真实测试 | 使用浏览器提交的分发配置 | 使用服务端托管配置 |
| 数据库身份识别 | 必须 | 必须 |
| 恢复和安全重装 | 后端状态允许时可用 | 仅在部署和维护规则允许时使用 |

## 安全原则

URL 参数不能伪造托管模式。托管状态必须来自服务端可信部署上下文。浏览器不得读取平台注入密码。
