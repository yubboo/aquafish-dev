# Aquafish 当前功能完成度

## 已形成底座

- Spring Boot 多模块工程和 Vue 管理端可独立构建。
- MySQL、MariaDB、PostgreSQL 与 R2DBC 迁移底座。
- 首次安装、数据库身份识别、恢复和安全重装。
- 主题扫描、校验、安装、升级、卸载、导出和父子继承。
- Thymeleaf、Pebble 双模板引擎。
- 活动主题、父主题、官方默认主题、核心 fallback 和紧急页面回退链。
- PF4J 独立 ClassLoader、插件依赖解析、Spring 子上下文和启停恢复。
- CMS、论坛、用户、授权及管理端的阶段性接口和页面。

## 尚未形成稳定生态

- 独立且可版本化的第三方插件 SDK。
- Hook、Filter、Event、Cell 和模板插槽调度。
- 插件权限、能力声明、签名、安装、升级和回滚。
- 插件管理端菜单、路由、页面与设置扩展。
- 可供主题作者稳定使用的 Aquafish 模板语法。
- 按主题和版本隔离的生产模板缓存。
- AI、搜索和市场模块的完整业务闭环。

## 当前判断

项目已经超过脚手架阶段，但仍属于平台内核建设期，不能把现有插件运行时等同于成熟插件生态。
