# Aquafish 当前项目状态

> 更新时间：2026-07-26。

## 项目定位

Aquafish 是 Java 21、Spring Boot 与 Vue 3 组成的 CMS、BBS、主题和插件平台。仓库继续采用与 Halo 相近的模块化单体和单仓组织，不拆分 Admin 与 Server 的源码仓库。

## 仓库边界

- `app/`：服务端、多模块领域代码、主题和插件运行时。
- `admin/`：Vue 3 + TypeScript 管理端。
- `docs/`：当前公开文档。
- `scripts/`：通用验证与发行辅助脚本。
- `backups/`、`deploy/`、本机工具和历史实施脚本不进入源码仓库。

## 当前阶段

工程构建、首次安装、多数据库迁移、主题生命周期、双模板引擎、模板回退、PF4J 插件生命周期以及部分 CMS/BBS 管理能力已经形成可测试底座。

下一阶段不继续横向铺开业务模块，优先稳定主题和插件生态契约。

## 前端核心工作区

管理端包名统一为 `@aquafish/aqadmin`，组件统一使用 `Aq` 前缀。用户中心应用标识固定为 `user`，不采用 Halo 的 `console`、`uc` 命名。

当前 `admin/` 已升级为 pnpm workspace，并建立四个第一阶段核心包：

- `admin/packages/components`：`@aquafish/components`，当前提供 `AqButton`、`AqStatus`、`AqPagination`。
- `admin/packages/api-client`：`@aquafish/api-client`，统一 Axios、Cookie、CSRF、401、403 与 423 行为。
- `admin/packages/ui-shared`：`@aquafish/ui-shared`，定义 `aqadmin`、`user` 应用标识和类型安全插件扩展点。
- `admin/packages/plugin-bundler-kit`：`@aquafish/plugin-bundler-kit`，校验 `plugin.yaml` 并生成受控插件 UI 产物。

主题管理页面已经接入 `AqButton`。认证、用户、授权、安装器、固定链接、主题和工作台领域 API 均已迁移到统一 Axios 客户端，旧的全局 Fetch Monkey Patch 已删除；测试会阻止生产源码重新直接调用 Fetch。

插件 UI 构建器当前固定生成 `main.js`、可选 `style.css` 与 `ui-manifest.json`，并强制 external Vue、Vue Router、Pinia、Axios 和 Aquafish 三个共享前端包。宿主侧静态资源控制器、全局运行时注入和动态注册器尚未开发，因此当前不能把构建产物描述为已能被 aqadmin 自动加载。
