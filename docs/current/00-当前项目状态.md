# Aquafish 当前项目状态

> 更新时间：2026-07-26。

## 项目定位

Aquafish 是 Java 21、Spring Boot 与 Vue 3 组成的 CMS、BBS、主题和插件平台。仓库继续采用与 Halo 相近的模块化单体和单仓组织，不拆分 Admin 与 Server 的源码仓库。

## 仓库边界

- `app/`：服务端、多模块领域代码、主题和插件运行时。
- `admin/`：Vue 3 + TypeScript 管理端。
- `docs/`：当前公开文档。
- `scripts/`：通用验证与发行辅助脚本。
- `backups/`、`deploy/`、本机工具和历史实施脚本不进入源码仓库。

## 当前阶段

工程构建、首次安装、多数据库迁移、主题生命周期、双模板引擎、模板回退、PF4J 插件生命周期以及部分 CMS/BBS 管理能力已经形成可测试底座。

下一阶段不继续横向铺开业务模块，优先稳定主题和插件生态契约。
