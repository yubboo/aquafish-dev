# Aquafish 当前运行与验收

## 环境

- JDK 21
- Node.js 22
- pnpm 11

## 管理端

```powershell
cd admin
pnpm install --frozen-lockfile
pnpm test
pnpm build
```

开发服务器固定监听 `http://127.0.0.1:18520`，并把 API 请求代理到
`http://127.0.0.1:8520`。

## 服务端

```powershell
cd app
.\gradlew.bat test --no-daemon
```

Spring Boot 默认监听 `8520` 端口。源码联调时前台与 API 使用该端口；发行
JAR 或 Docker 镜像内置管理端静态资源后，前台、管理端、安装页与 API
全部由该端口提供。

## 统一验证

