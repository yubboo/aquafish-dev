# Aquafish 开发与文档规范

> 根目录 CLAUDE.md 是最高优先级开发指令，本文件只记录 docs 维护规则。

## 开发规则

- 先阅读真实源码和当前文档，再修改。
- 一个功能模块一个目录，避免把多个功能堆在单文件。
- 新增或修改代码必须有清晰中文注释。
- 任何“已完成”结论必须有测试、构建或真实 UI 验收依据。
- 高风险数据库和授权操作必须 fail-closed。

## CJS 脚本

- 脚本放在 `docs/cjs`。
- 脚本修改前必须备份到 `backups`。
- 脚本必须支持 `node --check`。
- 检查失败时应自动恢复被修改文件。
- 不使用系统临时目录保存项目打包中间文件。

## 文档规则

- 当前文档只写入 docs/current、architecture、installation、deployment、development、api、decisions、progress。
- 旧实现和旧路线移入 docs/archive，不得继续作为当前指令。
- 根目录 CLAUDE.md 不得移动。
- 文档不得保存密码、密钥、Token、Cookie、私钥或完整授权凭据。
