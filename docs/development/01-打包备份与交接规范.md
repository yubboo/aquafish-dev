# Aquafish 打包备份与交接规范

> 源码快照、数据库备份和交接包统一放置，避免散落在项目根目录。

## 推荐目录

- 源码进度备份：`docs/export/progress-backups/`
- 修改前本地备份：`backups/`
- 长诊断报告：`backups/diagnostics/`

## 禁止

- 不把系统临时目录作为长期备份位置。
- 不把源码 ZIP、SQL 备份或交接包放在项目根目录。
- 不在交接包文档中写明文密码和密钥。

## 交接包最少包含

- 当前源码。
- docs 当前文档。
- 必要的数据库结构或安全脱敏备份。
- 当前测试与构建结果。
- 下一阶段计划和已知限制。
