# Aquafish 文档中心

本目录只把仍然有效的架构、开发、安装和验收资料作为公开文档。历史实施脚本、阶段性源码快照、验收截图和旧文档保留在开发机中，但不进入源码仓库。

## 阅读顺序

1. [当前项目状态](./current/00-当前项目状态.md)
2. [当前功能完成度](./current/01-当前功能完成度.md)
3. [当前运行与验收](./current/02-当前运行与验收.md)
4. [下一阶段开发计划](./current/03-下一阶段开发计划.md)
5. [总体架构](./architecture/00-总体架构.md)

## 目录

| 目录 | 内容 |
| --- | --- |
| `current/` | 当前状态、完成度、验收方式和下一阶段 |
| `architecture/` | 总体架构与模块边界 |
| `decisions/` | 已确认的架构决策记录 |
| `development/` | 开发和文档规范 |
| `installation/` | 安装、数据库识别与安全重装 |
| `deployment/` | 不同发行和部署模式的设计说明 |
| `api/` | 当前接口索引 |
| `progress/` | 仍有参考价值的阶段完成记录 |

## 文档规则

- `docs/current/` 是当前状态的唯一入口。
- 历史文档不能作为当前实现依据。
- 文档不得保存密码、Token、私钥、授权密钥或生产环境地址。
- 文档描述与源码不一致时，应在同一次变更中修正。
