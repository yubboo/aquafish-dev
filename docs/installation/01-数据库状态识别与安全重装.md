# Aquafish 数据库状态识别与安全重装

> 数据库身份识别和重装属于高风险边界，必须由后端权威判断。

## 状态

| 状态 | 含义 | 前端处理 |
|---|---|---|
| NEW_INSTALL | 空库或可安全首次安装 | 允许继续首次安装 |
| EXISTING_INSTALLED | 完整 Aquafish 实例 | 默认恢复现有安装，可选择重装 |
| INCOMPLETE_INSTALLATION | 不完整安装或残留 | 根据后端能力恢复或精确清理 |
| INCOMPATIBLE_DATABASE | 不兼容数据库 | 安全拦截并展示原因 |
| STATE_UNAVAILABLE | 状态无法识别 | 不得显示为通过，不得继续安装 |

## 测试门槛

`databaseResult` 只代表连接测试结果；`databaseInspection` 代表 Aquafish 身份和安装状态。只有两者都来自本次真实测试且状态可解释，才能标记数据库通过。

## 恢复

恢复现有安装不执行迁移建表和管理员创建，只恢复本机配置与安装锁，并要求后端重新确认状态。

## 安全重装

- 不执行 DROP DATABASE。
- 只处理当前表前缀下 Aquafish 正式白名单表和迁移表。
- 正式执行前后端重新检测数据库状态。
- 第一层确认重装模式和数据丢失。
- 第二层在安装执行前再次确认目标数据库、主机、端口和新管理员。
- 删除安装锁后必须重新回到 NEW_INSTALL，才允许继续。
