# Aquafish 分发包安装流程

> 适用于普通压缩包或手工部署，不适用于 Docker / 1Panel 托管数据库。

## 服务选择

- MySQL：默认推荐，默认端口 3306。
- MariaDB：面板环境兼容，默认端口 3306。
- PostgreSQL：复杂查询和扩展场景，默认端口 5432。
- Redis：可选增强，默认端口 6379。

## 连接填写

数据库和 Redis 在同一页左右展示。Redis 未选择时右侧保持基础模式说明，不展开连接字段，也不造成页面跳动。

## 真实测试

数据库测试包含两部分：

1. R2DBC 网络与认证连接。
2. Aquafish 数据库身份、版本、迁移和正式表识别。

只有取得本次测试结果后，数据库状态按钮才允许点击。修改数据库类型、主机、端口、数据库名、用户名、密码或表前缀后，旧结果必须立即失效。

Redis 启用后必须执行真实 AUTH、SELECT 和 PING；未启用时显示基础模式并跳过 Redis 测试。
