# Aquafish 安装器验收清单

> 每次修改 setup 前后端后都应按此清单回归。

## 分发包

- [ ] 数据库选择页显示三张数据库卡片和下方 Redis 卡片。
- [ ] 未选择数据库不能进入连接页。
- [ ] Redis 可选，未启用时使用基础模式。
- [ ] 左右连接表单在常见桌面分辨率下不产生无意义滚动。
- [ ] 手机端自动单列并可完整操作。

## 测试与状态

- [ ] 未测试时数据库状态按钮灰色且不可点击。
- [ ] 测试中按钮显示正在检测且不可点击。
- [ ] 测试完成后按钮文字按真实状态变化。
- [ ] 数据库和 Redis 显示真实耗时。
- [ ] 修改任意数据库参数后旧结果立即失效。
- [ ] STATE_UNAVAILABLE 不显示为数据库已通过。

## 恢复和重装

- [ ] EXISTING_INSTALLED 显示恢复与重装入口。
- [ ] 数据库状态内容在统一弹窗中展示。
- [ ] 第一层危险确认使用模糊遮罩。
- [ ] 正式安装前仍显示最终确认弹窗。
- [ ] 取消任一弹窗不会执行数据库写操作。
- [ ] 非 Aquafish 表和其他数据库不受影响。

## 托管部署

- [ ] Docker / 1Panel 不进入浏览器数据库选择和填写。
- [ ] 平台数据库和 Redis 密码不会回传浏览器。
